LibroTrack - Library Management System (Java Swing + MySQL)

1. Run database/library_db.sql in MySQL Workbench.
2. Add the MySQL Connector/J .jar to the project libraries.
3. Open src/util/DBConnection.java and put your MySQL password in PASS.
4. Run src/util/DBConnection.java once. It should print "Connected to MySQL!".
5. Run src/view/LoginFrame.java to start the program.
