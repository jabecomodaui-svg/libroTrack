mysql.jar — ang JDBC driver maka help sa Java nga ma connect sa MySQL database.

Question:

Ngaa need gid sang mysql.jar?

Ang mysql.jar need sa imo System kay amo ini ang MySQL JDBC Driver nga nagabulig sa Java application mo nga ma connect kag ma communicate sa MySQL database.

Bisan may database_connection.java, kinahanglan gihapon ang mysql.jar kay ang una amo ang connection code mo, while ang ikaduha amo ang driver nga ginagamit sang Java para ma connect sa MySQL.
